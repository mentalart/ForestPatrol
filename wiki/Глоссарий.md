# Глоссарий

Слова, которые встречаются в игре и в этой вики.

| Слово | Значение |
|---|---|
| **Богатырский выход** | полная синяя шкала + Смена: второй герой выходит с особой силой (см. [[Бой]]) |
| **Богатырский мах** | удар вдвоём по огромному Пробою босса |
| **Богатырский щит** | защита вдвоём в одну долю — держит самое большое |
| **Богатырское время** | цель испытания на [[Заставе|Застава-трёх-богатырей]] |
| **Весточка** | помощь от помощника из Сказа на весь следующий мир |
| **Гусельный уровень** | ритм-уровень: прыжки и защита в такт музыке |
| **Доля** | один удар музыки, такт. «В долю» — точно в такт |
| **Звенья** | части Златой цепи — главная цель уровней |
| **Звенышко** | живое звено цепи, проводник героев |
| **Искры** | счётчик внутри уровня; наполняют синюю шкалу |
| **Колокольчик** | точка возврата на уровне |
| **«Ко мне!»** | позвать друга (1 / 0 / крестовина ↑) |
| **Лад** | серия попаданий в такт подряд — множитель искр |
| **Лепестки** | здоровье героя, три у каждого игрока |
| **Морок** | враг: нитяной клубок в облике существа; удар его распутывает |
| **Оставленный держит** | после Смены прежний герой продолжает держать плиту, перо, напев |
| **Орешки** | валюта лавки Векши |
| **Подкидка** | приём Потапа — бросить друга |
| **Подшивание** | друг встаёт, если рядом постоять секунду |
| **Пробой** | морок оглушён: все угольки погасли — можно бить |
| **Самоцветы** | бонусная валюта: лубки, карты тайников, Застава |
| **Светомостки / тенемостки** | золотые мостки держат в свете, лиловые — в темноте |
| **Сказ** | сказка, которую герои сочиняют после босса |
| **Смена** | переключение на другого своего героя (Q / K / Y) |
| **Совиный взор** | приём Пелагеи — видеть скрытое |
| **Угольки** | запал морока: гаснут от защит и ударов |
| **Чудо-вещь** | особый предмет мира на RB (см. [[Чудо-вещи]]) |

## Цветные знаки
| Знак | Значит |
|---|---|
| 🟡 жёлтый кружок / солнышко | щит в такт |
| 🔴 красный зубец | уйти или кувырок |
| 🔵 синяя капля | отбить обратно |
| 🟢 / 🟠 / 🟣 колечко цвета игрока | что возьмут клещи, кто держит угол невода |
| ✨ золотая нить | путь к цели |
