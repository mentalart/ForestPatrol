# Добро пожаловать в вики «Златой цепи»!

**«Златая цепь»** (рабочее название проекта — «Лесной патруль») — кооперативная 3D-сказка для детей 7–10 лет по мотивам русских сказок и Пушкина. Двое игроков (или один в [[одиночном режиме|Одиночный-режим]]) ведут четверых друзей — [[Прошку|Прошка]], [[Потапа|Потап]], [[Пелагею|Пелагея]] и [[Йошу|Йоша]] — через пять сказочных миров, чтобы собрать по звену **Златую цепь** на дубе у Лукоморья и вернуть Коту Учёному голос.

| | |
|---|---|
| **Жанр** | кооперативный приключенческий платформер с головоломками и ритм-уровнями |
| **Игроки** | 2 на одном экране (клавиатура и/или два джойстика) или 1 в одиночном режиме |
| **Возраст** | 7–10 лет (подсказки написаны для детей 9 лет) |
| **Платформа** | браузер (Chrome, Edge, Firefox), без установки |
| **Текущая версия** | final06 — вся игра озвучена (1030 реплик), см. [[Версии]] |
| **Играть** | **[онлайн на GitHub Pages](https://mentalart.github.io/ForestPatrol/)** · [скачать файл](https://github.com/mentalart/ForestPatrol/releases) |

> ⚠️ **О спойлерах.** Страницы про сюжет, боссов и концовки раскрывают повороты истории. Такие места помечены значком 🔒.
