# Разработка

Страница для тех, кто правит игру. Подробные правила — `CLAUDE.md`, `MAP.md` и `zlataya_cep/docs/rabota.md` в репозитории.

## Как устроен репозиторий
| Папка | Что там |
|---|---|
| `proto/` | **прототип** (Three.js r128) по частям: движок `proto/engine/`, по файлу на уровень `proto/levels/` |
| `zlataya_cep/build/` | **модули релиза**: общие — в корне, уровня — в `levels/<уровень>/`; замены `rep_*.py`; озвучка `voice/` |
| `zlataya_cep/docs/` | документы студии, журнал изменений `changes/` |
| `tools/tests/` | боты-тесты на Playwright |
| `tools/script/`, `tools/voice/`, `tools/video/` | тексты для сценариста, озвучка, трейлер |
| `wiki/` | **эта вики** |

## Собрать игру
```sh
python3 zlataya_cep/build/build_final.py            # релиз → zlataya_cep/zlataya_cep_final06.html
python3 zlataya_cep/build/build_final.py --pages out # лёгкая версия для Pages: out/index.html + out/voice/*.mp3
python3 tools/proto.py                               # прототип → index.html
```

## Найти место в коде
```sh
python3 tools/map.py where 2-2          # уровень: файл прототипа, модули, замены, боты
python3 tools/map.py where lullStage    # функция или имя
```

## Тесты
- `python3 tools/tests/affected.py` — какие боты затрагивает правка.
- Локально — только новые и изменённые боты: `BOTS="бот1 бот2" tools/tests/regress.sh zlataya_cep/zlataya_cep_final06.html`.
- Весь набор, а при необходимости полный регресс, гоняет CI на каждом PR по 8 машинам; итог — проверка `bots`.
- Раз в неделю — сводка неустойчивых ботов (issue «Неустойчивые боты — сводка CI»).

## Как вносить правки
1. Ветка от свежей `main`.
2. Правка, бот, запись журнала: `python3 tools/changelog.py new "Заголовок"`.
3. PR → **автослияние** — PR вливается сам, когда `bots` зелёная.
4. После слияния игра сама выкладывается на Pages и в Releases.

## Как править эту вики
Вики собирается из папки [`wiki/`](https://github.com/mentalart/ForestPatrol/tree/main/wiki) в репозитории: правьте файлы там через PR. После слияния в `main` workflow «Вики» сам переносит страницы в раздел **Wiki** на GitHub.
- Страница — файл `Название-Страницы.md` (дефисы станут пробелами в заголовке).
- Ссылки между страницами: `[[Текст|Название-Страницы]]`.
- Картинки — в `wiki/images/`; снимки уровней обновляет `node tools/wiki_shots.js [уровень …]` (релиз сначала собрать).
- `_Sidebar.md` — меню слева, `_Footer.md` — подвал.
