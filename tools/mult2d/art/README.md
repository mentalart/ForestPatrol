# Арт 2D-мультсериала (ChatGPT)

Нарисовано в ChatGPT (октябрь 2026) по промптам раздела 4 `zlataya_cep/docs/47_mult2d_stil.md`: приставка стиля + шаблон листа
+ описание героя. Каждый герой — отдельный диалог: сначала модельный лист, затем в том же диалоге лист деталей.
PNG уменьшены до 2048 px по длинной стороне. Фон белый, rembg ещё не применялся.

| Папка | `sheet.png` — модельный лист | `parts.png` — детали для перекладки |
|---|---|---|
| `pelageya/` | 4 ракурса + 3 эмоции, стиль «бумага» | голова, тело, крылья, лапы, глаза, 8 ртов |
| `zvenyshko/` | то же; из двух вариантов ChatGPT выбран бумажный, с просветом в кольце | кольцо спереди и в ¾, свечение, золотая нить, глаза, рты |
| `koschei/` | стиль «лак» (Палех), на белом фоне | голова, корона, одежда, руки, глаза, рты |
| `kot/` | стиль «бумага» | голова, кафтан, рукава, лапы, хвост, глаза в очках, рты |

Отступления от шаблона: в лист деталей Звенышка добавлено «This character has no arms, legs or tail: instead of them give the
empty golden ring body (front and three-quarter), the warm glow halo and the golden thread trail as separate pieces» — без
этого ChatGPT пририсовывает руки и ноги (несколько мелких «лапок» всё равно остались, их можно не брать).
