# Трейлер «Златой цепи»

Трёхминутный трейлер снимается ботами из релизной сборки `zlataya_cep/zlataya_cep_final06.html`. В нём:
1. Заставка студии АбадзехLAB — та же, что в игре.
2. Стартовое меню.
3. Шоты по 4–6 с из прохождения: пролог со сценкой с самокатом, все пять миров и боссы, новый 5-1 с Лихом, бой с Кощеем в пять этапов,
   Лукоморье, Застава, эпилог; одиночный режим и кооператив, общий экран и два экрана. Персонажи говорят своими голосами (final06).
4. Титул в конце.

```sh
node tools/video/trailer.js --preview --out /tmp/prev   # проверка шотов: 3 кадра в секунду
node tools/video/trailer.js                             # кадры: tools/video/out/NN_id/*.jpg, 24 кадра в секунду, 1280×720
for k in 0 1 2; do node tools/video/trailer.js --part $k/3 & done; wait   # то же в три процесса (примерно вдвое-втрое быстрее)
node tools/video/audio.js                               # звук: tools/video/out/audio.webm
tools/video/encode.sh                                   # tools/video/out/trailer.mp4 (H.264 + AAC)
node tools/video/trailer.js --only w3_song,w4_boss      # переснять отдельные шоты (потом снова audio.js и encode.sh)
node tools/video/trailer.js --preview --shots мои.js --out /tmp/scout   # разведка: свой список шотов, 3 кадра в секунду
```

## Как это устроено
- `shots.js` — список шотов: уровень, момент, режим автопилота, трек музыки.
  - `CINE(id,t)` — вступительный ролик уровня на секунде t.
  - `PLAY(id,o)` — пропустить ролики и дать уровню устояться. Флаги `o`: `solo` — одиночный режим, `apart` — развести героев на два экрана, `foes` — позвать мороков к героям.
  - `PRO(t)` — пролог: герои на жёлтых пятнах, ролик «Колыбельная» на секунде t.
  - `GOR(t)` — 4-Б: левая и правая головы в Пробое, ролик рыка (лавовые трещины, гейзеры) на секунде t.
  - `W51(часть,s)` — 5-1 с нужной части (`warp51`: head, lagoon, meadow, glade, keys, boss1…3).
  - `K5S(n,s)` — 5-Б2, этап n без обучающих карточек, s секунд боя под автопилотом `k5`; `K5W(n,t)` — ролик после победы на этапе n.
  - Перемотка к моменту шота идёт отдельным шагом, после паузы: записи голосов уровня успевают раскодироваться.
- `autopilot.js` — выполняется в странице. Ведёт героев шаг за игровым тиком теми же приёмами, что боты `tools/tests`:
  - бой: отбив на жёлтом, кувырок от красного, удары по открытому;
  - песня 3-3 и «Калинка» 5-4 — точно в долю;
  - ходьба;
  - бой с Кощеем (`k5`) — как бот `tfin_koshcoop`: свечи, искорка, шар другу и в небо, «око», заход со спины, игла, ковка.

  Там же:
  - запись звуков: каждый вызов `tone()` и `FIN.aud.osc/nz` со временем видео;
  - запись голосов: хук модуля озвучки `FIN.voxEv` сообщает, какая запись и когда зазвучала (реплика, смех «поверх», затихание);
    реплика, начатая до шота, переносится с нужного места;
  - часы интерфейса: CSS-анимации идут по времени видео.
- `trailer.js` снимает кадр за кадром. На каждый кадр: шаг автопилота, тики игры, отрисовка кадра, скриншот страницы (HUD и субтитры в кадре). Игровой цикл `requestAnimationFrame` выключен. Готовые сегменты пропускаются, поэтому съёмку можно прерывать и продолжать.
- `audio.js` открывает игру и пишет её собственный звук в реальном времени (MediaRecorder):
  - музыка — `FIN.music`, трек каждого сегмента из `meta.json`. В игре музыка нарочно тихая, поэтому в трейлере она в 4 раза громче
    (`MUSIC_GAIN=…`), а тихие треки (boss, hub, w1, w5 — на 10–20 дБ тише title) подняты отдельно;
  - эффекты — записанные при съёмке вызовы синтеза в те же мгновения, так что звук совпадает с картинкой;
  - голоса — записи реплик из релиза в те же мгновения: новая реплика обрывает прежнюю, смех «поверх» — нет, на стыке шотов реплика
    затихает, музыка на время голоса тише. Голос заставки — на 1,8 с.
- `encode.sh` склеивает кадры и звук в MP4 и делает короткие затемнения в начале и в конце. Сначала переводит `audio.webm` в WAV по
  сэмплам: метки времени MediaRecorder «плывут», и без этого звук короче видео. Громкость выравнивает `dynaudnorm`, чтобы сегменты
  с одной музыкой не проваливались рядом с голосами. Нужен ffmpeg с libx264: если его нет в `PATH`, используется `imageio-ffmpeg` (`pip install imageio-ffmpeg`).

В headless-браузере кадр рисуется программно (SwiftShader): около 2–3 с на кадр, поэтому в один процесс трейлер снимается 3–4 часа, в три (`--part k/3`) —
примерно вдвое-втрое быстрее. Готовые кадры и видео лежат в `tools/video/out/` и в git не кладутся.
