# Трейлер «Златой цепи»

Трёхминутный трейлер снимается ботами из релизной сборки `zlataya_cep/zlataya_cep_final05.html`. В нём:
1. Заставка студии АбадзехLAB — та же, что в игре.
2. Стартовое меню.
3. Шоты по 4–6 с из прохождения: все пять миров, боссы, Лукоморье, Застава, эпилог; одиночный режим и кооператив, общий экран и два экрана.
4. Титул в конце.

```sh
node tools/video/trailer.js --preview --out /tmp/prev   # проверка шотов: 3 кадра в секунду
node tools/video/trailer.js                             # кадры: tools/video/out/NN_id/*.jpg, 24 кадра в секунду, 1280×720
node tools/video/audio.js                               # звук: tools/video/out/audio.webm
tools/video/encode.sh                                   # tools/video/out/trailer.mp4 (H.264 + AAC)
node tools/video/trailer.js --only w3_song,w4_boss      # переснять отдельные шоты (потом снова audio.js и encode.sh)
```

## Как это устроено
- `shots.js` — список шотов: уровень, момент, режим автопилота, трек музыки.
  - `CINE(id,t)` — вступительный ролик уровня на секунде t.
  - `PLAY(id,o)` — пропустить ролики и дать уровню устояться. Флаги `o`: `solo` — одиночный режим, `apart` — развести героев на два экрана, `foes` — позвать мороков к героям.
- `autopilot.js` — выполняется в странице. Ведёт героев шаг за игровым тиком теми же приёмами, что боты `tools/tests`:
  - бой: отбив на жёлтом, кувырок от красного, удары по открытому;
  - песня 3-3 и «Калинка» 5-4 — точно в долю;
  - ходьба.

  Там же:
  - запись звуков: каждый вызов `tone()` и `FIN.aud.osc/nz` со временем видео;
  - часы интерфейса: CSS-анимации идут по времени видео.
- `trailer.js` снимает кадр за кадром. На каждый кадр: шаг автопилота, тики игры, отрисовка кадра, скриншот страницы (HUD и субтитры в кадре). Игровой цикл `requestAnimationFrame` выключен. Готовые сегменты пропускаются, поэтому съёмку можно прерывать и продолжать.
- `audio.js` открывает игру и пишет её собственный звук в реальном времени (MediaRecorder):
  - музыка — `FIN.music`, трек каждого сегмента из `meta.json`;
  - эффекты — записанные при съёмке вызовы синтеза в те же мгновения, так что звук совпадает с картинкой.
- `encode.sh` склеивает кадры и звук в MP4 и делает короткие затемнения в начале и в конце. Нужен ffmpeg с libx264: если его нет в `PATH`, используется `imageio-ffmpeg` (`pip install imageio-ffmpeg`).

В headless-браузере кадр рисуется программно (SwiftShader): около 2–3 с на кадр, поэтому трейлер снимается 3–4 часа. Готовые кадры и видео лежат в `tools/video/out/` и в git не кладутся.
