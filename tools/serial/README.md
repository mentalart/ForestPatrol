# Мультсериал «Златая цепь» — съёмка серий (вертикаль 9:16)

Сценарий сезона и постановочный сценарий серии 1 — `zlataya_cep/docs/46_multserial.md`. Серии снимаются движком игры из релизной
сборки: те же модели, площадки роликов, музыка, звуки и записанные голоса. **В игру код серий не входит**: `build.js` вставляет его
в копию релиза `tools/serial/out/serial.html`. Готовые кадры и видео лежат в `tools/serial/out/` и в git не кладутся.

```sh
python3 zlataya_cep/build/build_final.py                       # релиз (если не собран)
node tools/serial/build.js                                     # съёмочная сборка: релиз + core.js + ep*.js
node tools/serial/shoot.js --ep 1 --preview                    # предпросмотр: 3 кадра/с, 360×640 → out/ep01_prev
node tools/serial/shoot.js --ep 1                              # кадры 720×1280, 24 кадра/с → out/ep01/NN_id/*.jpg
for k in 0 1 2; do node tools/serial/shoot.js --ep 1 --part $k/3 & done; wait   # то же в три процесса
node tools/serial/shoot.js --ep 1 --only f_final,g_koschei     # переснять отдельные сегменты
node tools/serial/shoot.js --ep 1 --sound-only                 # только метки звука по снятым кадрам (быстро, без отрисовки)
node tools/serial/audio.js --ep 1                              # звук: out/ep01/audio.webm (в реальном времени)
tools/serial/encode.sh tools/serial/out/ep01                   # out/ep01/ep01.mp4 — 1080×1920, H.264 + AAC
```

## Как устроено
- `core.js` — общий код серий (одна область видимости с модулями релиза, как `late_*.js`):
  - **кадр 9:16**: интерфейс игры скрыт, свои субтитры (имя говорящего цветом героя, по центру на 64 % высоты — над кнопками ленты),
    лента с именем героя «Присказки» — сверху, титры и карточки (`SER.card`), затемнение (`SER.fade`);
    взгляд камеры чуть ниже цели (`SER.tilt`) — лица поднимаются в верхние две трети кадра;
  - **герои для крупных планов**: глаза крупнее (×1,22) и веки в покое подняты — лицо открытое (в игре не меняется);
  - **реплики**: `say` в съёмке не играет голос и «бормотание» — показывает субтитр и пишет метку голоса (`FIN.vox.find` по тексту);
  - **звук**: вызовы синтеза (`tone`, `AUD.osc/nz`), инструменты песен (`FIN.music.inst`) и смена музыки пишутся в `SER.log` со временем видео
    (ноты самой музыки — секвенсор `FIN.music.tick` в `render` — не пишутся: дорожка играет музыку сама по меткам смены трека);
  - **сегменты**: `SER.prkScene(i,o)` — сцена «Присказки» (0…6), `SER.lullaby(o)` — «Колыбельная» пролога, `SER.own(def)` — своя сцена
    на площадках «Присказки»; `o` — подмена поверх ролика игры (`SER.over`): `shots`/`reshot` (вертикальные планы `KS` по времени ролика),
    `says`/`addSays`/`dropSays`, `cues`, `tick`, `mood`;
  - `SER.seg(ep,i)` строит сегмент и проматывает к `from` (реплика, начатая раньше, переносится, только если у сегмента `carry:true`),
    `SER.frame(i,t,dt)` — кадр (тики игры по 1/60, в среднем ровно dt).
- `ep01.js` … — серии: `SER.eps[N]={title,segs:[{id,from,to,setup,carry,tilt}]}`; сегменты идут подряд, склейки — жёсткие.
- `shoot.js` — съёмка кадр за кадром (как трейлер `tools/video/trailer.js`): игровой цикл выключен, CSS-переходы идут по времени видео,
  случайные числа сегмента — от его имени (переснятый сегмент совпадает с прежним). В headless кадр рисуется программно (SwiftShader):
  720×1280 — около 2 с на кадр, серия 2:16 (3260 кадров) — ~2 ч в один процесс, в три — около 45 мин.
- `audio.js` — звуковая дорожка в реальном времени (MediaRecorder): музыка в 4 раза громче игровой (`MUSIC_GAIN`), тихие треки подняты,
  под голосом музыка тише; новая реплика обрывает прежнюю, на стыке сегментов реплика затихает.
- `encode.sh` — склейка в MP4 1080×1920 (масштаб lanczos), выравнивание громкости (`dynaudnorm`), короткие затемнения в начале и в конце.
