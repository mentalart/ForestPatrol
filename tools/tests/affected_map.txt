# Какие боты проверяют изменённый файл — для tools/tests/affected.py (выборочный регресс).
# Строка: путь (glob от корня репозитория; «#слово» — только правки под заголовком «# ---- …слово…» в rep_*.py) → что гонять:
#   имена ботов; @level:<id> — все боты, которые загружают этот уровень (LV('id'), loadLevel(N), U.go() — пролог);
#   @wide — широкий набор (всё, что рисует мир и персонажей на всех уровнях); @full — полный регресс; «-» — ботов не нужно.
# Первое совпадение сверху вниз. Файла нет в таблице — полный регресс (и скрипт напомнит дописать его сюда).
# index.html здесь не описан: скрипт сам находит изменённые функции уровней (buildXX) и уровни, которые вызывают изменённую функцию.
