# Измерительные скрипты аудита боссов

Это инструменты, которыми сняты числа в `zlataya_cep/docs/34_boss_audit.md` (раздел 2 «Метрики»). Код игры они **не меняют**: релиз
копируется, в копию вставляется перехватчик (`probe.js`), существующие боты `tools/tests/bots/*.js` гоняются на этой копии, а логи
разбирают скрипты на Python. Ядро будущего постоянного бота-аудитора — задача F-0 бэклога (`docs/34` §6.2); эти скрипты — её прототип
и способ повторить замер на любой версии.

## Быстрый старт

```bash
python3 zlataya_cep/build/build_final.py                    # релиз (в git не лежит)
export BOSS_AUDIT_OUT=/tmp/boss_audit                       # куда писать логи (по умолчанию /tmp/boss_audit)
tools/boss_audit/run_bot.sh tfin_k2bboss                    # бот под перехватчиком → $BOSS_AUDIT_OUT/tfin_k2bboss.json
python3 tools/boss_audit/metrics.py                         # слова, озвучка, ролики, тряска, перекрытия → metrics.json
python3 tools/boss_audit/mk_tables.py                       # те же числа таблицами Markdown (metrics_tables.md)
python3 tools/boss_audit/mk_perf.py                         # вызовы / треугольники / частицы по боссам
tools/boss_audit/run_audio.sh && python3 tools/boss_audit/audio_table.py   # громкость шин (нужен свободный процессор)
```

Какие боты нужны для каждого босса — словарь `B` в `metrics.py` (1-Б: `tfin_k1b*`, 2-Б: `tfin_k2b*`, 3-Б: `tfin_k3b*`, 4-Б: `tfin_boss4b`,
`tfin_gor4`…, 5-Б1: `t5b1`, 5-Б2: `tk5e_*`, мини-боссы: `tfin_sky31boss`, `tfin_sky32boss`, `tfin_k21`, `t51`, `tfin_yaga11`). Боты запускаются
**по одному**, последовательно (иначе в программном рендере кадры растягиваются и числа плывут); `TO=секунды` — таймаут,
`SHOTS=1` — снимки в `$BOSS_AUDIT_OUT/frames/<метка>`, `RELEASE=путь` — другой релиз.

## Что есть

| Файл | Что делает |
|---|---|
| `probe.js` | Перехватчик: оборачивает `tip/banner/say/sayP/floatText/play/prompt/shake`, `CINE.trauma/flashDip`; каждые 6 тиков снимает HUD (`hint0/1/S`, `banner`, `subs`, `finBossHint`, `finTut`, `bossbar`, `skip`…: текст, прямоугольник, размер шрифта); считает вспышки `#flash`, hit-stop; раз в 120 тиков делает принудительную `render()` + `gl.finish()` и пишет `renderer.info` (вызовы, треугольники), живые частицы `FIN.fx.list`. Включается `PR.on=true`. |
| `probe_aud.js` | Анализаторы на шинах `JM.mus/sfx/vox` и выходе лимитера `JM.lim` (пик, RMS среднее и максимум, dBFS); `PR.musPlay`, `PR.voxPlay`, `PR.snd.*`. |
| `hint_words.py` | Статический поиск подсказок боссов длиннее нормы (F-2h3): `python3 tools/boss_audit/hint_words.py [--max N] [--all]` — таблица «уровень · файл:строка · вызов · слов · озвучено · текст» по `tip`/`tipZones`/`t4HintShow`/`b32HintShow` боссовых уровней и общего кода; код 1, если есть неозвученные длиннее нормы. |
| `make_probe.py` | Копия релиза с `probe.js` (`--audio` — и `probe_aud.js`) перед концом игровой IIFE (после `if(window.ZC)window.ZC.FIN=FIN;`). |
| `run_bot.sh` | Гонит бот из `tools/tests/bots/` на копии, пишет лог событий `<метка>.json`. |
| `metrics.py` | Из логов: слова `TIP`/подписей баннеров (среднее, максимум, доля > 7), время на экране с учётом `tipMul` мира, читаемость (0,5 / 1,7 слова/с), озвучено реплик, длительности роликов, тряска (максимум, пик в секунду), hit-stop, вспышки, перекрытия HUD (≥ 10 % меньшего окна). `tmin` у Рака и Лихо — окно самого боя. |
| `mk_tables.py` | Таблицы раздела 2 `docs/34` из `metrics.json`. |
| `mk_perf.py` | Нагрузка на отрисовку (p95 и максимум); кадры загрузки уровня (≥ 1200 вызовов) и «залипшие» замеры отбрасываются. |
| `run_audio.sh`, `audio/*.js`, `audio_table.py` | Громкость: темы музыки (мир, бой, этапы 1-Б/2-Б/3-Б), звуки удара/сигналы/рыки, мороковые «бормотания», записанные голоса. |
| `jsx.py`, `inv.py` | Статический экстрактор русских строк из JS (контекст вызова, число слов, озвучена ли): `inv.py <имя> файл.js…` → `$BOSS_AUDIT_OUT/inv_<имя>.tsv`. |
| `hints.py`, `lv.py`, `overlap.py`, `vfxstat.py` | Разбор одного лога: таблица показанных текстов, просмотр событий, пересечения HUD, тряска/вспышки в секунду. |
| `uisize.js` | Реальные размеры шрифтов элементов интерфейса на окнах 1280×720, 1920×1080, 1024×576. |

## Ограничения (читать перед тем, как верить числам)
- **Боты играют идеально**, поэтому длительности этапов — нижняя граница; ребёнок ×2–3 (`[ГИПОТЕЗА]`, `docs/34`).
- **Время кадра не измеряется**: рендер программный (SwiftShader), нагрузка на машину искажает его. Берём вызовы, треугольники, частицы.
- **Громкость** — на выходе до звуковой карты, на слух не проверено; при загруженном процессоре цикл отрисовки встаёт и музыка занижается на десятки дБ, поэтому `run_audio.sh` запускать на свободной машине. Повторные прогоны различаются на 1–3 дБ; первая тема в прогоне может быть занижена нарастанием громкости.
- Перехватчик должен включаться **после** инициализации игры и только на копии релиза: в постоянном коде он живёт под `?debug` (задача F-0).
- Числа в `docs/34` сняты на `main` 2026-10-08 (после PR #72); при сравнении с новой версией прогоняйте всё заново, а не по частям.
