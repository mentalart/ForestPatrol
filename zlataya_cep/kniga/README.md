# Книга трёх миров

Раскладная (pop-up) книга по мотивам «Златой цепи»: обложка и три объёмных разворота —
**Дремучий лес**, **Подводный Китеж**, **Небесное царство**. Отдельная страница, в игру не входит.

- Файл — `kniga.html`, один, без картинок: всё рисуется на canvas при загрузке. Three.js r128 с cdnjs
  (как в игре), без сети — запасной `../build/three.r128.min.js`. Открыть можно прямо из папки.
- На Pages после слияния в `main`: https://mentalart.github.io/ForestPatrol/kniga/
- Управление: стрелки внизу, клавиши ← →, нажатие на правую или левую страницу. Мышью или пальцем
  можно повернуть камеру, колесо или щипок приближают, двойной щелчок возвращает вид. На каждом
  развороте спрятано золотое звено: нажмите на него. Звук (шелест страниц, хлопок раскрытия,
  перезвон) — WebAudio, без файлов.

## Как устроено
- Листы (обложка, два листа, задняя обложка) вращаются вокруг корешка (ось Z), толщина стопки
  перетекает со стороны на сторону вместе с углом листа.
- У разворота своя рамка на корешке, повёрнутая по биссектрисе двух его страниц; `ψ` — половина угла
  раскрытия (π/2 — книга лежит раскрытой, 0 — сомкнута). Всё объёмное считается от `ψ`:
  - **V-слои** (`layers`: фон, средний план, передний план) стоят поперёк корешка и складываются по
    сгибу к зрителю: `x = s·sinψ`, `y = |s|·cosψ + v·sinψ`, `z = z0 + v·cosψ`;
  - **фигуры** (`pieces`) стоят на своей странице и ложатся на неё, наклон ограничен так, чтобы не
    задеть встречную страницу.
- Состав разворотов — массив `SPREADS` (слои, фигуры с `x, z, yaw`, звено, частицы). Новая фигура —
  функция рисования `art(ширина, высота, (ctx,w,h)=>…)` в единицах сцены и строка в `pieces`;
  `z + высота` не больше 0,6, иначе в сложенной книге фигура вылезет за обрез.
- Для проверок: `KNIGA.go(n)` — сразу открыть разворот `n` (−1 — закрыть), `KNIGA.set(лист, угол)`.
  Кадр: `node tools/tests/shot.js zlataya_cep/kniga/kniga.html out.png "KNIGA.go(1)" 2500`.
