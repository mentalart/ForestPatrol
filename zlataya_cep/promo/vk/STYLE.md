# «Златая цепь» — оформление картинок для постов ВК

Стиль «Книжка Пелагеи», бумажная аппликация. Иллюстрации рисует ChatGPT, текст на картинки
накладывает код (`zc_style.py`): ChatGPT путает кириллицу, а код набирает её чисто и каждый раз одинаково.

В `src/` лежат стайлборд (`styleboard.jpg`, его прикладывать в новый диалог ChatGPT) и иллюстрации героев
(Прошка, Потап, Пелагея, Йоша, Кот Учёный): они служат образцами персонажей и годятся для раскладок вроде опроса.
Образцы постов — `POSTS` в `make_posts.py`. Описания героев — `../../docs/47_mult2d_stil.md`.

---

## 1. Как устроена карточка поста (1080×1350, 4:5)

```
┌───────────────────────────────────┐  ← кремовая бумажная страница #FBF3E2, виньетка
│✿ орнамент              орнамент ✿│  ← уголки хохломы (assets/corner.png) — всегда два сверху
│ ┌───────────────────────────────┐ │
│ │ [● Игрок 1]                   │ │  ← бейдж игрока (только у героев): оранжевый 1 / бирюзовый 2
│ │       ИЛЛЮСТРАЦИЯ             │ │  ← «вырезанное» окно: неровный край, тень внутрь, светлый срез
│ │       (ChatGPT, 3:2)          │ │
│ ├─────[ ЛЕНТА-РУБРИКА ]──(печать)┤ │  ← золотая лента с надписью по дуге + круглая печать справа
│ │           Заголовок           │ │  ← Kurale, кремовый, ≈92 px
│ │        подзаголовок           │ │  ← Caveat Bold, золото (необязательно)
│ │          ○-○-○-○-○            │ │  ← золотая цепь из пяти звеньев — разделитель, всегда
│ │ ★ пункт / абзац / «цитата»    │ │  ← Nunito Bold 34–40 px, кремовый
│ │ Ваш Кот Учёный, с дуба…       │ │  ← подпись Caveat, золото
│ └──────── цветная плашка ───────┘ │  ← цвет рубрики/героя
└───────────────────────────────────┘
```

Высота окна под иллюстрацию подбирается сама: окно максимально большое, но основной текст
не мельче 36 px. Если текста много, окно ниже. Текст поста лучше сокращать до 2–3 коротких пунктов.

## 2. Палитра

| Назначение | Цвет |
|---|---|
| Страница | `#FBF3E2` (251, 243, 226) |
| Текст на плашке | `#FFF6E0` кремовый |
| Золотая нить, подзаголовок, подпись | `#F0C04A` |
| Текст на ленте | `#4A2212` тёмно-коричневый |

**Плашки** (цвет = рубрика или герой; тона темнее палитры мультсериала, чтобы кремовый текст читался):

| Ключ | Цвет | Когда |
|---|---|---|
| `moss` | `#2D6B4A` | лес, Кот Учёный, общие новости |
| `ginger` | `#CD5226` | Прошка, игрок 1 |
| `lilac` | `#7C52B8` | Пелагея |
| `turquoise` | `#14807A` | Йоша, игрок 2 |
| `kitezh` | `#186080` | Китеж, вода, «Откуда это в сказке» |
| `night` | `#24305E` | загадки, ночь, Кощей |
| `cinnabar` | `#B63228` | мастерская, разработка |

Для Потапа и Кузьмы ещё нет своих цветов. Предложение: Потап — `ginger` или бурый `#8A5A2B`, Кузьма — `cinnabar`.

## 3. Рубрики

| Рубрика (лента) | Плашка | Печать | Состав |
|---|---|---|---|
| **Знакомьтесь** | цвет героя | `stamp_paw` / `stamp_book` / `stamp_fish` | имя + роль (подзаголовок) + 3 пункта со звёздочками + бейдж «Игрок N» |
| **Откуда это в сказке** | `kitezh` | `stamp_bell` | заголовок-понятие + 2 абзаца: предание → как это в игре |
| **Загадка от Кота** | `night` | `stamp_key` | «Угадай-ка!» + загадка цитатой + «Ответ пишите в комментариях…» |
| **Мастерская** | `cinnabar` | `stamp_anvil` | скриншоты игры «фотокарточками» на скотче + бирки + 1–2 фразы |

Печати лежат в `assets/`: `stamp_book`, `stamp_bell`, `stamp_anvil`, `stamp_key`, `stamp_paw`, `stamp_fish`.
Ещё в `assets/`: `chain5` (цепь), `ribbon` (лента), `corner` (орнамент), `star` (маркер пункта),
`zvenyshko` (Звенышко с глазами, пока не используется; подойдёт для анонсов).

## 4. Шрифты (все с кириллицей, OFL, лежат в `fonts/`)

| Роль | Шрифт |
|---|---|
| Заголовок, цитаты | **Kurale** — сказочная антиква |
| Основной текст | **Nunito** Bold / ExtraBold — круглый, детский, хорошо читается |
| Лента, бейджи | **Rubik** Black / Bold, ЗАГЛАВНЫЕ |
| Подзаголовок, подпись Кота | **Caveat** Bold — рукописный |

## 5. Правила текста

- Заголовок короткий: одно-два слова, до 20 знаков (длинный автоматически уменьшается, но не меньше 56 px).
- На картинке тезисы, а не весь текст поста: 3 пункта по одной строке или 2 коротких абзаца.
- Типографика включается сама: неразрывный пробел перед «—» и после коротких слов (в, и, на, не…), кавычки «ёлочки».
- В стихах (цитатах) переносы ставьте сами через `\n`.
- Подпись: «Ваш Кот Учёный, с дуба у Лукоморья»; в постах о разработке — «Ваш Кот Учёный · Лаборатория игр «АбадзехLAB»».
- Буква «ё» обязательна.

## 6. Иллюстрация в ChatGPT

Генерировать в **одном диалоге** (там есть стайлборд, и стиль держится). Формат — альбомный 3:2,
**без текста**, главный объект по центру с запасом по краям: края подрежутся под окно.

**Приставка к каждому запросу:**

> Same cut-paper pop-up book style and palette, landscape 3:2, full-bleed scene (no frame, no card, no ribbon),
> main subject centered with breathing room at the edges, NO text anywhere.

Если диалог новый, начать его со стартового промпта из `PROMPT_START.md` (там же, что приложить).

**Описания героев** — из `47_mult2d_stil.md`, раздел 4 (Прошка, Потап, Пелагея, Йоша, Тишка, Звенышко,
Кот Учёный, Кузьма; для Кощея — стиль «лак»). Кот Учёный в группе: серый полосатый, большие зелёные глаза,
круглые очки, золотой ошейник-цепь, кафтан с золотым орнаментом, свиток.

**Загадки:** отгадку не показывать. Персонаж только силуэтом, «mysterious but kind, NOT scary».

## 7. Как собрать новый пост

```bash
pip install pillow numpy scipy          # один раз
```

1. Сохранить иллюстрацию из ChatGPT в `src/<имя>.png`.
2. Добавить запись в `POSTS` в `make_posts.py`, например:

```python
'p7_potap': dict(art='potap', kicker='Знакомьтесь', title='Потап', subtitle='медвежонок-силач',
    bullets=['Подбросит друзей туда, куда сами не допрыгнут.',
             'Сдвинет камень и удержит ворота.',
             'Добрый, неторопливый и всегда за своих.'],
    panel='ginger', stamp='stamp_paw', player=1),
```

3. `python make_posts.py p7_potap` → готовая картинка в `out/p7_potap.jpg`.

Параметры `post_card`: `kicker`, `title`, `subtitle`, `bullets` (список), `text` (абзацы через `\n`),
`quote`, `panel`, `stamp`, `player` (1/2), `signature`, `art_focus=(x, y)` (какую часть иллюстрации
сохранить при обрезке, 0..1), `art_h` (задать высоту окна вручную), `window_fill` (своя раскладка окна,
как фотокарточки в «Мастерской»).

## 8. Обложка и аватар

- **Обложка** 1920×768: `cover(art)`. Табличка с названием сверху по центру, плашка-приглашение снизу.
  Всё важное держать в центральных ~1100 px: на телефоне ВК показывает середину.
  В запросе к ChatGPT: «keep the upper-middle part as calm open sky, all characters in the lower half
  and central 60% width».
- **Аватар** 1000×1000: `avatar(art)`. Портрет Кота по центру (голова ≈60% кадра), лучи мха и золота,
  золотое кольцо по краю круга. Проверить, что читается при размере 50 px.

## 9. Загрузка в ВК

- Замена картинки в посте: «…» → «Редактировать» → добавить новое фото → удалить старое → «Далее» → «Сохранить».
  Лайки и комментарии сохраняются, у отложенных постов сохраняется дата.
- Аватар: при смене снимите галочку «Опубликовать в посте», если не нужен отдельный пост.
- Обложка: «Управление сообществом» → «Обложка: Управление» → «Обложка на сайте».

## 10. Проверка перед публикацией

- [ ] Нет текста от ChatGPT внутри иллюстрации (буквы-каракули на вывесках, книгах).
- [ ] Заголовок и пункты не налезают на печать и цепь; подпись не прижата к тексту.
- [ ] Цвет плашки соответствует рубрике или герою; бейдж игрока верный (1 — Прошка и Потап, 2 — Пелагея и Йоша).
- [ ] Герои похожи на описания из `47_mult2d_stil.md`.
- [ ] Картинка 1080×1350, JPEG.
