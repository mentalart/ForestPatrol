## Общий шаблон урока и «Показать урок ещё раз»
- Движок интерактивных роликов 4-Б вынесен в общий модуль `FIN.lesson` (`late_79e_lesson.js`): шаг ждёт нажатия, через 8 с герои показывают приём сами, пропуск и «осталось N с» — как у всех роликов, озвучка шага по id реплики, сокращённое «Напоминание». Уроки 4-Б переведены на шаблон — поведение прежнее.
- В паузе, если у текущего места есть урок (4-Б, этапы 1–3), появился пункт «Показать урок ещё раз»; хук `FIN.lesson.again()` годится для повтора после падений.
