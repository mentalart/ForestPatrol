## Работа быстрее, третий круг: модули по папкам уровней, крупные модули по частям, журнал по файлам, лёгкая версия для Pages
- Модули и замены одного уровня — в его папке `zlataya_cep/build/levels/<уровень>/` (`levels/2-2/`, `levels/5-B2/`, общий для мира 2 —
  `levels/w2/`), общие — в `build/`. Порядок подключения — по имени файла, как раньше: релиз собирается побайтно тот же.
  Правка уровня — две папки: `proto/levels/<уровень>.js` и `build/levels/<уровень>/`.
- `affected.py`: перенос файла без правок — не правка; новый файл в папке уровня сам находит ботов уровня (папка мира — всех его уровней).
  `map.py`, `extract.js`, `apply_edits.js` ищут модули по папкам; правка сценариста по старому снимку находит модуль на новом месте.
- Лукоморье (`proto/levels/luko.js`, 1070 строк) — шесть частей по 70–240 строк: сцена, миры 1–3, миры 4–5, Застава/кузня/карта,
  наряды/пляски/огород, праздник и ролик.
- Крупнейшие модули — по частям по 20–38 КБ: 5-Б2 `late_93_koschei_level` — на 5 (`…_p2_storm` … `…_p5_finale`), 2-2 `late_99f_k22`
  и 2-1 `late_99e_k21` — на 4. Части склеиваются сборкой по имени файла; правка этапа — чтение одной части.
- **Журнал изменений — по файлу на задачу** в `docs/changes/` (`python3 tools/changelog.py new "Заголовок"`): общий `CHANGELOG.md`
  конфликтовал при каждом слиянии веток двух аккаунтов; весь журнал — `python3 tools/changelog.py`.
- **Pages — лёгкая версия**: `index.html` ~4 МБ вместо 27 (голоса — 876 отдельных файлов `voice/<id>.mp3`, подгружаются при загрузке уровня,
  `build_final.py --pages`); цельный файл для скачивания — в Releases и рядом на Pages, как прежде.
- **`CLAUDE.md` короче**: подробности (сценарист, озвучка, конфликты, final07) — в `zlataya_cep/docs/rabota.md`.
