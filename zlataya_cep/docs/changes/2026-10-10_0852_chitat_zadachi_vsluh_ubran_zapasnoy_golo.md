## Читать задачи вслух: убран запасной голос браузера (Microsoft Irina)
- «Читать задачи вслух» читает только записанным голосом (Байя). Голос браузера (Web Speech API — в Windows это Microsoft Irina) убран совсем: `speechSynthesis` в игре больше не вызывается, в настройках нет строки «запасной: …».
- Текст без записи (новый или изменённый; карточки обучения боссов, живая подсказка Горыныча, табличка Соловья) теперь молчит, а не читается голосом браузера. Озвучить новое: `tools/voice/read_tts.py` (docs/09_final06.md). Громкость «Голоса» 0 — тишина.
- `late_79b_readaloud.js` — без голоса браузера (`RA.ok`, `RA.voice` убраны; `RA.mock` для ботов остался), `late_91d_readvoice.js` — запись или тишина (счётчик `FIN.readVoice.fallback` → `failed`). Вики «FAQ», «Мир 1», доки 09 и 27.
- Бот `tfin_readvoice`: `speechSynthesis.speak` не вызывается ни разу, статус без «запасного» голоса, текст без записи молчит.
