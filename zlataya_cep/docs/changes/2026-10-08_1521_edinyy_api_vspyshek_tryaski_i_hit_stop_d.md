## Единый API вспышек, тряски и hit-stop для боссов
- Новый модуль `late_84b_bossfx.js` — `FIN.bossfx`: общие `flash`, `light`, `shake`, `hitstop`, `tele` с потолками стандарта (вспышек ≤ 3 в секунду, на весь экран ≤ 1 за 8 с, тряска ≤ 0,09, hit-stop ≤ 0,16 с).
- Молнии 2-Б и `#flash` в 5-Б2 (штормовые вспышки, вспышка провала стадии) подчинены «Вспышкам»: 0 % — нет, 50 % — вдвое слабее.
- Бот `tfin_flash`; в вики — раздел про вспышки и тряску в боях с боссами.
