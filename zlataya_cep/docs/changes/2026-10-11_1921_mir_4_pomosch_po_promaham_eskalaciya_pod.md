## Мир 4: помощь по промахам, эскалация подсказок 4-Б, невидимые правила
- 4-1 … 4-5: промах (неудачное нажатие или падение в огонь) поднимает помощь на ступень — короткая подсказка с кнопкой → подсказка и стрелка над целью → короткий повтор урока; 20 с без промахов — снова с первой ступени (`build/levels/w4/late_99w4_help.js`). В ковке вдвоём «рано/поздно» теперь со звуком промаха.
- 4-Б: живые подсказки больше не перебирают темы по кругу — удар по герою или 12 с без успеха поднимают ступень: мигает кнопка → карточка и стрелка → короткое напоминание этапа; верное нажатие сбрасывает (`late_87_boss4b.js`, находка 4Б-4 из `docs/34`).
- Весточка из Сказа 3 в начале каждого уровня мира 4 — одной подсказкой; над лавой без пера Жар-птицы Пелагея в первый раз дымится — «Жар крылья не держит!» (`late_99w4_rules.js`). Весточка Сирин в 4-3 расширяет окно «ух-нем» (0,16 с с каждой стороны).
