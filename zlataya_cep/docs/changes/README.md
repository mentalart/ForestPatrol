# Журнал изменений — по файлу на задачу

Каждая задача (ветка, PR) пишет свою запись здесь, а не в общий `../CHANGELOG.md`: две ветки, дописавшие общий файл сверху,
конфликтовали при каждом слиянии. Отдельные файлы не конфликтуют никогда.

- Новая запись: `python3 tools/changelog.py new "Заголовок задачи"` — создаёт `ГГГГ-ММ-ДД_ЧЧММ_<слово>.md` с заголовком `## …`;
  пункты — строками `- …`; коммит вместе с правкой.
- Весь журнал по порядку (новые сверху, затем история из `CHANGELOG.md`): `python3 tools/changelog.py`, последние N записей — `… N`.
- `CHANGELOG.md` — история до перехода на отдельные файлы, больше не правится.
