## Вики игры на GitHub
- Вики по образцу игровых вики (Minecraft Wiki, Terraria Wiki): 33 страницы — главная с порталами и меню, быстрый старт, управление,
  одиночный режим, четверо героев с карточками, персонажи, пять миров с прохождением каждого уровня, пролог и эпилог, бой,
  чудо-вещи, бестиарий (угольки и сигналы каждого морока — из кода), боссы, Лукоморье, Застава, экономика, Сказы и концовки
  (с пометками о спойлерах), глоссарий, частые вопросы, версии, разработка; 36 снимков уровней.
- Исходник — папка `wiki/` (правки через PR); после слияния в `main` workflow «Вики» переносит её в раздел Wiki.
  Один раз нужно включить Wiki в настройках и создать первую страницу.
- `tools/wiki_shots.js` — снимки уровней без интерфейса для вики.
