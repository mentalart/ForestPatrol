## 2D-мультсериал: навык perekladka, голоса без акцента, сериал во ВКонтакте
- Навык `perekladka` (`.claude/skills/perekladka/`): перекладка (cut-out) 2D-сериала — 12 принципов анимации для кукол из деталей, игра на реплике, темп монтажа 9:16, лист оснастки для ChatGPT, оценка сцены /14 и как развивать конвейер.
- Движок `tools/mult2d/engine.js`: замах и перелёт (`MD.anticip`), пружина (`MD.spring`), запаздывание (`MD.lag`), позы на n кадров (`MD.steps`), автоморгание, дыхание, «дрожь бумаги»; высота субтитров — `ep.subY`.
- Голоса: русские образцы для клонирования без акцента (`tools/mult2d/voice/refs/`, из озвучки игры) и реплики пробы с ударениями (`voice/proba/lines.json`).
- Предложение анимационного сериала для группы ВКонтакте — `zlataya_cep/docs/48_vk_serial_predlozhenie.md`: идея «Позови в круг», рубрики, лаборатории визуальных решений и сюжета, приглашение в игру, пилот и меры.
