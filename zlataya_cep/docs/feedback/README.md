# Опросы тестеров «Златой цепи»

Четыре интерактивных опроса для тех, кто прошёл игру (версия final05): по ним команда собирает отзывы о сюжете, механиках, уровнях,
интерфейсе, визуальном стиле, звуке и технической стороне. У каждой возрастной группы свой набор вопросов: младшие оценивают то,
что могут оценить, а подростки и взрослые разбирают игру подробнее.

| Файл | Кому | Глав / вопросов | Как устроен |
|---|---|---|---|
| `opros_7-8.html` | 7–8 лет | 6 / 36 | три рожицы, карточки-картинки, чтение вслух, рисунок; подсказка взрослым, что ответы можно записать за ребёнка |
| `opros_9-10.html` | 9–10 лет | 7 / 45 | пять рожиц, оценка миров и боссов по строкам, Лукоморье, чтение вслух, рисунок |
| `opros_11-13.html` | 11–13 лет | 7 / 57 | шкалы 1–5, сложность по мирам, способности, кооператив и одиночный режим, баги, NPS |
| `opros_14plus.html` | 14 лет и взрослые (в том числе родители) | 9 / 51 | утверждения «согласен — не согласен» по нарративу, механики, UX и доступность, визуал, звук, техника, цена, NPS |

Часть вопросов появляется только при нужном ответе (например, «Где это было?» — после «Да, застревал»); все вопросы необязательны.
Страницы оформлены по мирам игры (лес, Китеж, небо, Смородина): герои на холме у дуба с золотой цепью, летающее Звенышко,
главы с анимированными кадрами уровней, прогресс в виде цепи из звеньев, конфетти в конце. Есть светлая и тёмная тема, вёрстка
под телефон, а если в системе включено «уменьшить движение» — без анимаций.

## Где лежат и как заполнять
- **Опубликованные страницы** (ответы сохраняются в базу опроса, владелец видит все, каждый участник — только свои):
  [7–8 лет](https://claude.ai/artifact/2vpWnApTFVbggRi4aWAxXk) ·
  [9–10 лет](https://claude.ai/artifact/9KqLWHpRf8DMVb7kKETaXY) ·
  [11–13 лет](https://claude.ai/artifact/7UW5nW3RnqV3xKGu8ov9X7) ·
  [14+ и взрослые](https://claude.ai/artifact/Bqpc3ce5CW2cm4MbcXaqVN).
  Записывать ответы могут те, кому страница открыта с правом «Участник» (Contributor) или выше; у остальных, как и в файловых
  копиях, в конце появляются кнопки «Скопировать ответы» и «Сохранить файлом» — ответы пересылают организатору теста.
- **Файлы в этой папке** открываются прямо в браузере и работают без интернета: шрифты встроены в страницу, картинки берутся
  из `assets/`. Черновик ответов хранится в браузере, так что опрос можно закрыть и продолжить позже.
- **Архивы для тестеров** (`zlataya-cep_opros_*.zip`, 0,8–1 МБ): папка со страницей, только нужными ей картинками, инструкцией
  `README.txt` и лицензией шрифтов. Распаковать и дважды щёлкнуть HTML; ответы — кнопкой «Сохранить файлом» (JSON в «Загрузках»).

## Что сохраняется
Каждая отправка — документ `responses/<id участника>/entries/<id>`:
`{form:"zc-opros-v1", age, game:"final05", submittedAt, durationSec, answered, total, answers:{id вопроса: ответ}, qa:[[глава, вопрос, ответ]]}`.
В `answers` рожицы, звёзды и шкалы записаны числами 1–5 (NPS — 0–10), выбор карточек и кнопок — подписью, строки таблиц —
объектом `{строка: балл | "na"}`, рисунок — JPEG в data URL. `qa` дублирует ответы текстом, чтобы их можно было читать без
расшифровки. Имя и почта не собираются; контакт для повторного теста оставляют только взрослые и только по желанию.

## Сборка
Содержание опросов — `src/surveys.js`, общий шаблон страницы — `src/page.html`. После правок:

```
node zlataya_cep/docs/feedback/src/build.js            # пересобрать opros_*.html
node zlataya_cep/docs/feedback/src/build.js --pub DIR  # ещё и версии для публикации + DIR/assets.json (какие картинки нужны)
node zlataya_cep/docs/feedback/src/build.js --zip DIR  # ещё и архивы для работы без интернета: DIR/zlataya-cep_opros_*.zip
```

Шрифты Nunito, Podkova и Ruslan Display (SIL OFL 1.1, `src/fonts/OFL.txt`) лежат в `src/fonts/`: в копиях и архивах они встроены
в страницу, опубликованные страницы берут их с Google Fonts.

Картинки в `assets/` отрендерены из релизной сборки игры: стикеры персонажей (`st_*`, прозрачный фон) и кадры уровней (`bg_*`).
