# Арт-ресёрч: 5 стилей и 200 промтов для Qwen Image

> Документ собирает `python3 tools/art_prompts.py` — руками не править: стили, сущности и акценты меняются в скрипте, потом пересборка.

Цель — подобрать игре «Златая цепь» собственный визуальный стиль. Пять стилей, у каждого — одни и те же **40 сущностей** (герои, жители, все мороки, мини-боссы и боссы, места, ключевые предметы, геймплей): **5 × 40 = 200 картинок**. Композиция картинки одной сущности во всех стилях одинаковая — меняется только стиль, поэтому пять вариантов легко сравнивать рядом.

## 1. Инструкция для агента генерации (MCP)

| параметр | значение |
|---|---|
| модель | **Qwen Image 2.1** |
| размер | **1280 × 720** (720p, 16:9) для всех 200 картинок |
| папка | `C:\_UE_PRJs_\ZolotayCepGame\wiki\images\_ArtResearch\` |
| имя файла | из заголовка промта, например `S1_H01_proshka.png` (стиль · сущность · имя) |
| промт | блок `text` под заголовком — **дословно**, на английском: не переводить, не сокращать, не дописывать |
| негатив | `negative: NEG_Sx` — текст после `NEG_Sx:` в блоке негатива этого стиля (раздел 2), если инструмент принимает negative prompt |
| seed | указан у каждого промта (повторяемость); для новых вариантов того же промта — другой seed |
| шаги / CFG | по умолчанию модели; если инструмент спрашивает — 30–50 шагов, CFG ≈ 4 |

**Порядок работы:**
1. Создать папку `C:\_UE_PRJs_\ZolotayCepGame\wiki\images\_ArtResearch`, если её нет.
2. Генерировать только промты раздела 5 (блоки раздела 2 — части стилей, не отдельные картинки), строго по номерам 001 → 200. Если файл с таким именем уже есть в папке — пропустить (так генерацию можно прервать и продолжить с того же места).
3. **Каждое изображение сохранять в папку сразу по готовности**, не дожидаясь конца пачки: инструмент вернул ссылку — скачать сразу; вернул base64 — записать файл; сохранил в свою папку — сразу скопировать в `_ArtResearch` под именем из заголовка.
4. Ошибка генерации — один повтор с тем же seed, потом с seed + 1; не вышло — записать строку в `_ArtResearch\_errors.txt` (номер, имя файла, ошибка) и идти дальше.
5. Если инструмент не принимает 1280×720 (нужна кратность 32/64) — ближайший размер 16:9 (`1280×704`, `1344×768`) без кадрирования; имя файла то же.
6. Ничего не коммитить: `wiki/` уходит в GitHub Wiki после слияния в `main`, а 200 PNG — это сотни мегабайт. В репозиторий — только выбранные картинки, уменьшенные и в JPG.

**Волна 1 (001–040)** — восемь главных сущностей во всех стилях: четыре героя, команда, Кощей, Лукоморье и совместная загадка. Этого хватает для первого отбора: после неё можно остановиться, отсеять 2–3 стиля и догенерировать остальное только по оставшимся. **Волна 2 (041–200)** — все остальные сущности.

### S1 · «Резная сказка» — Carved Folk Toy

- **Что это.** Герои и мир — расписные деревянные игрушки богородских и семёновских мастеров: крупные рубленые формы со следами стамески, мягкие фаски, матовая темпера по липе, городецкие цветы и точки-бусины. Мир — настольная диорама.
- **Почему подходит игре.** Прямое развитие нынешней арт-библии («вырезанная из дерева сказка», грань вместо глянца), поэтому меньше всего риска. Тёплый, «игрушечный», хорошо читается с изометрической камеры.
- **Как это делать в Unreal.** Стилизованный PBR: фаски, шум по вершинам, запечённый AO, матовые материалы с волокном дерева; дёшево в производстве.
- **Палитра:** охра, киноварь, хвойная зелень, сливочный, золото. **Ориентиры:** богородская игрушка, городецкая и полхов-майданская роспись, Synty POLYGON, A Short Hike.

### S2 · «Валяная сказка» — Felt & Embroidery Stop-Motion

- **Почему подходит игре.** Продолжает то, что уже есть в игре: вышитая карта-рушник и льняные полотна-переходы между уровнями; мороки — нитяные клубки, которые распутываются, — в этом стиле буквально из ниток. Самый уютный и «семейный».

## 4. Как выбирать

Смотреть сначала стиль целиком (все `S1_*` подряд — цельный ли мир), потом одну сущность в пяти стилях (поиск `*_H01_*`). Оценки по пятибалльной шкале:

| критерий | S1 | S2 | S3 | S4 | S5 |
|---|---|---|---|---|---|
| Узнаётся «русская сказка» с первого взгляда | | | | | |
| Героев видно и понятно с изометрической камеры (силуэт, цвет) | | | | | |
| Мороки читаются как враги, но не пугают детей 7–11 лет | | | | | |
| Боссы — зрелищные | | | | | |
| Места разных миров не похожи друг на друга | | | | | |
| Предметы и то, с чем можно взаимодействовать, выделяются | | | | | |
| Не похоже на другие игры | | | | | |
| Посильно в производстве (Unreal, малая команда) | | | | | |
| Нравится самому (и детям-тестерам) | | | | | |

Стили можно смешивать: например, герои и мороки — «Валяная сказка», ролики-Сказы — «Бумажный театр», интерфейс и карта — «Книжка Билибина». Следующий шаг после выбора — листы персонажей (вид спереди, сбоку, сзади), кадры-эталоны для каждого мира и пробный материал в Unreal.
