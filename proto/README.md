# Прототип по частям

Исходник прототипа «Златой цепи» (Three.js r128). Части, склеенные подряд в порядке `parts.txt`, дают `index.html` байт в байт:
`python3 tools/proto.py` (сборка релиза `zlataya_cep/build/build_final.py` делает это сама). `index.html` в git не хранится.

- `head.html` — разметка, стили и комментарий об отличиях от сценария; `tail.html` — конец страницы.
- `engine/` — движок по разделам (заголовки `/* ==== … ==== */` внутри): ввод и звук, рендер и герои, мир и коллизии, физика и действия,
  мороки (язык боя), урон и клубок, реквизит, Звенышко и камера, HUD и ролики; `10_levels_flow_menu.js` — таблица `LEVELS`, поток игры,
  меню, `window.ZC`.
- `levels/` — по файлу на уровень (`1-1.js` … `5-B2.js`, `p_prologue.js`, `luko.js`, `epi.js`, `zastava.js`); перед уровнями мира — его
  общий код (`w1_common.js` — жители мира 1, `w2_common.js` — вода и гусли, `w3_common.js` — свет и перо, `w4_common.js` — клещи
  и лава, `w5_common.js` — знаки, Лихо, шкура).

Все части — одна область видимости (один `<script>`): функции из любой части видны всем. Где что — `python3 tools/map.py where …`;
строка склейки → часть — `python3 tools/proto.py line N`; цельный `index.html` из старой ветки → части — `python3 tools/proto.py split файл`.
