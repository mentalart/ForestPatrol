# Златая цепь — заметки для работы в репозитории

- Прототип игры — один файл `index.html` (Three.js r128). Релизная low-poly версия — `zlataya_cep/zlataya_cep_final02.html` (предыдущий релиз `zlataya_cep_final01.html` лежит рядом и больше не пересобирается); она собирается из прототипа командой `python3 zlataya_cep/build/build_final.py`. Прототип при этом не меняется; сам релизный файл вручную не правится — только модули в `zlataya_cep/build/`, после чего релиз пересобирается. Документы студии лежат в `zlataya_cep/docs/`. Описание уровней и управления — `README.md`, список отличий от сценария — комментарий в начале `index.html`.
- Тесты-боты лежат в `tools/tests/` (как запускать — `tools/tests/README.md`). Полный регресс: `tools/tests/regress.sh`.
- Любой новый или изменённый бот сразу кладите в `tools/tests/bots/` (и при необходимости в `tools/tests/regress_list.txt`) и коммитьте вместе с изменением игры — боты не должны жить только во временных папках.
- Перед коммитом изменений геймплея прогоняйте затронутые боты, а для крупных правок — полный регресс. Изменения релизного слоя проверяйте на релизной сборке: `LIST=tools/tests/regress_list_final.txt tools/tests/regress.sh zlataya_cep/zlataya_cep_final02.html`.
- Модули релиза живут в одной области видимости с прототипом: оборачивайте функции прототипа присваиванием (`step=function…`), но не объявляйте функций с их именами — сборка это проверяет и останавливается.
