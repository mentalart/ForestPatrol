## Рецепты (Three.js r128, без сборщика; модули — одна область видимости с прототипом)

### Обёртка действия, а не правка прототипа
```js
// late_NN_<тема>.js — каждый шаг под своим флагом, выключенный = прежнее поведение
const SOK={on:true,f:{land:true,pick:true},stats:{land:0,pick:0}};FIN.sok=SOK;
const skOn=k=>SOK.on&&SOK.f[k]&&(typeof JX==='undefined'||JX.on);
{const _land=SFX.land;SFX.land=function(){const r=_land.apply(this,arguments);if(skOn('land')){/* отклик */SOK.stats.land++;}return r;};}
```
Нельзя объявлять `function` с именем функции прототипа — сборка проверит; только присваивание.

### Сжатие-растяжение героя (с сохранением объёма и возвратом к покою)
```js
// h.body — группа тела героя; масштаб задаётся заново каждый кадр из своей пружины, не умножается (иначе «копится» на 144 Гц)
const sqSet=(h,a)=>{h._sq={v:0,x:a};};                   // a>0 — сплющить (приземление), a<0 — вытянуть (прыжок)
W.updates.push(dt=>{for(const h of HEROES){const s=h._sq;if(!s)continue;
  s.v+=(-s.x*260-s.v*22)*dt;s.x+=s.v*dt;                   // пружина с лёгким перелётом
  if(Math.abs(s.x)<0.002&&Math.abs(s.v)<0.02){h._sq=null;h.body.scale.set(1,1,1);continue;}
  const y=1-s.x,xz=1/Math.sqrt(Math.max(0.3,y));h.body.scale.set(xz,y,xz);}});
```
`W.updates` очищается при загрузке уровня — для общего слоя подписываться обёрткой `step` (как в `late_91b`).
Проверить, что сжатие не спорит с анимацией героя и с `late_83` (пружины ушей).

### Стоп-кадр (hit-stop)
Готовый — `G.hitstop=Math.max(G.hitstop, сек*JX.s.hs)`. Не писать свой таймер: игра в стопе стоит, ввод буферизуется движком.
Длительности по ступеням: 0,05 (лёгкий), 0,07–0,09 (отбив, кора), 0,11–0,16 (добивание, босс). Один раз на попадание.

### Тряска
Только `shake(pi,amp,dur)` — она уже × `FIN.shakeK()` и трясёт камеру своей половины. Амплитуды: 0,02–0,03 (приземление),
0,04–0,05 (удар), ≤ 0,09 (крупное), разово ≤ 0,15. Не трясти обе половины экрана событием одного игрока.

### Вспышка
Белый силуэт морока — как в `late_91h_punch` (материалы общие: подменять `emissive`/цвет на время и возвращать, прозрачность не
трогать). Сила — `jxFl()`: при 50 % — вдвое короче, при 0 — нет. Полноэкранные — только крупная ступень, ≤ 1 за 8 с.

### Звук
`AUD.nz({f0,f1,d,v,a,q,pan,wet})`, `AUD.osc({type,f0,f1,d,v,glide,pan})`, `AUD.bell(f,{v,d,wet,pan})`; громкость — через `jxV`,
панорама — `jxPan(pos,pi)` (своя половина экрана). Атака `a` ≥ 0,002 с для щелчка, но общий пик — без резких громких звуков.
Нота награды — `jxLad(n)` (лад мира), серия — по лесенке. Вес героя — множитель `jxK(h)` к частоте и длительности.

### Частицы
`FX.sparks / dust / sparkle / leaves / stars / confetti(pos,…)` — посмотреть сигнатуру через `where FX.<имя>`. Семейство морока —
`DTH_FAM[e.def.look]` (нить, вода, лес, огонь, свет) — цвет и форма частиц по нему. Лимит — ≤ 120 живых на пике вчетвером.

### Измерение в боте
```js

const P0=ZC.players[0],h=P0.heroes[P0.act],y0=h.pos.y;ZC.press(U.K[0].j);let n=0;
while(h.pos.y===y0&&n<20){ZC.tick(1);n++;}
return ['jump_first_frame',n,n<=3?'ok':'FAIL slow'];
```
Образец — `tools/tests/bots/tfin_punchy.js` (`FIN.dbgFoe`, `FIN.dbgHit` — морок и удар по требованию). Клавиши — `U.K`
(`helpers.js`), устройство — `tools/tests/README.md`. В боте `FIN` — это `ZC.FIN`. Счётчики слоя (`ZC.FIN.punch.stats`,
`ZC.FIN.sok.stats`) возвращать последней строкой: «до/после» сравнивается без кадров.

## Частые ошибки
- Тряска тела героя вместо камеры — ломает коллизии и прицел.
- Случайный сдвиг каждый кадр вместо шума — «жужжит»; тряска должна затухать сама.
- Сочность на каждом шаге четырёх героев — каша и усталость; шаги по поверхностям уже отвергнуты (`docs/23`).
- Отклик «залипает»: масштаб не вернулся, музыка осталась в приседе, стоп повторяется на удержании.
- Добавить эффект, не дав флага выключения, — нечего сравнить и нечем откатить.
- Забыть настройки «Тряска»/«Вспышки» и раздельный экран.
